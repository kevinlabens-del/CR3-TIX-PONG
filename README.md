# CR3@TIX PONG

Un jeu d’arcade opposant la Glace et le Feu, créé par CR3@TIX.

## Jouer

https://kevinlabens-del.github.io/CR3-TIX-PONG/

## Fonctionnalités

- campagne Ascension de 12 arènes ;
- trois combats de boss ;
- modes solo et duel local ;
- pouvoirs Surcharge, Bouclier et Titan ;
- progression, étoiles, fragments et signatures visuelles ;
- commandes tactiles et clavier ;
- installation sur mobile et fonctionnement hors connexion ;
- affichage responsive en portrait, paysage et plein écran.

## Déploiement

Le projet source se trouve dans `source/`. La version statique validée est publiée depuis la branche `gh-pages` avec GitHub Pages.
